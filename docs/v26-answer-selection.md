# v26 條件 PPL 答案選擇

同一個完整題目條件有多個合格答案時，以固定 v26 checkpoint 的答案 PPL 最低者作為訓練標準答案。此規則取代來源順序、教師名稱及答案長度的優先選擇；一千萬筆目標與原有品質要求維持不變。

固定模型為 `voidful/barbet-skill@67131067ff1825179d5e38e91d499159669e9c66`，使用已快取的發布權重、原生 tokenizer、chat template 及保留 BF16／FP32 混合精度的原載入器。沒有訓練、更新權重或呼叫付費服務。

PPL 定義為 `exp(sum(answer token NLL) / answer token count)`。答案包含每個受監督 assistant 回合及其 EOS；題目、技能、記憶、工具觀察、非監督歷史及 padding 不計入分母。完整先前脈絡仍供因果預測使用，不截斷再宣稱等價。工具規格、觀察、任務限制或非監督歷史不同者屬於不同條件。

OpenOrca 的 12 種確切通用教師風格提示，依版本化白名單移除後，在共同的技能與題目條件下比較答案。使用者題目與答案不改寫；不在白名單內的情境規則與指定輸出格式保留。這是新版本資料轉換，原始來源、首票失敗、前版匯出與雜湊均保留。

實機校準發現 padding 批次與逐筆分數最多差 `0.0109908792` mean NLL；不同 attention 計算路徑也造成原生 loss 比對差異。此批次方案未通過原定容差，失敗記錄保留。正式評分因此固定 batch size 1、完整未補齊序列、FlashAttention、按原始序列對齊的 128-token vocabulary projection、FP32 cross entropy、FP64 加總。以同一計算路徑重新驗證後，三個控制案例重複分數完全一致，與模型原生 loss 的最大差為 `2.4912e-8`。這是工程一致性檢查，不是模型能力提升。

選擇前仍執行來源授權、首票負面 hold、污染排除、因果順序、工具型別與宣告參數等規則。任何候選缺少分數、出現非有限值或完整上下文超出預算，整個競爭群組先保留為 hold；不能自動選剩餘第一筆。PPL 相同時以穩定 record ID 決定。每個候選保存答案 token 數、NLL、PPL、完整輸入雜湊、模型與程式版本。

PPL 低表示模型較容易預測，不保證答案正確。資料來源的上游品質標記、獨立檢查範圍與首次語意審查結果必須另報。校準中的錯誤答案也比某個簡短正確答案得到更低 PPL，正好說明不能用 PPL 取代正確性門檻。

程式入口為 `prepare_v26_answer_candidates.py`、`validate_v26_canonical_ppl.py` 與 `score_v26_answer_candidates.py`。候選索引從第一、二批去重前的正規化檔案重建，因此先前僅因來源排序而失去的答案仍可參與。正規化前就被排除的原始列，不能宣稱已經評過分；後續恢復範圍須有獨立來源與排除理由檢查。

原始候選池的 479,012 組、1,077,235 個答案已實際評分完成，沒有失敗群組。補查另外 231,472 筆僅因先前出現相同首題而被略過的原始列後，115,217 筆已在索引，103,988 筆是尚未收錄的合格候選，其餘仍依原始品質規則排除。`recover_v26_overlap_candidates.py` 保留舊資料、評測、首次負面及來源品質排除，只撤除這個與答案品質無關的去重步驟。

擴充後索引包含 3,600,061 個不同候選答案、3,001,384 個完整輸入群組，其中 479,466 組有競爭答案，共 1,078,143 個已評分答案。原有 1,077,235 筆數值分數經原始檔案 SHA256、逐候選來源位置、模型及評分程式雜湊核對後沿用；新增的 908 個競爭答案均經實際 v26 推論。新的 protocol 綁定擴充候選池，另保留原分數資料庫及 protocol 雜湊，不改寫原始分數。只有一個合格答案的條件不宣稱已測 PPL。

`extend_v26_overlap_selection.py` 重新檢查完整對話身分：257,917 個嚴格對話前綴視圖，以及 1,696 個同任務但觀察條件不同的候選先隔離。另在來源檢查中發現兩個只有年份、沒有壽命或得獎事實的 OpenOrca 知識查詢，被舊啟發式誤判為數學題，已排除這兩個來源條件。相同短題目但有完整文件的 HotpotQA 條件不受此排除影響。

完整發布入口為 `build_v26_complete_release.py`。它重新核對最低 PPL、凍結家族切分、執行首次選中答案診斷，再建立全列 token、labels、answer-free inference 預算與匿名公開讀回證明。前述候選數與已評分答案數不是最終合格資料筆數。

目前第二批依來源順序合併的發佈方案已標記 superseded，發布器在網路寫入前拒絕它。待新的選擇、完整 token／label／推論預算檢查與匿名讀回完成，才更新現役 Hugging Face 資料。既有已發布版本留在歷史中，擴充目標保持進行。

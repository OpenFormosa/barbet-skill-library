Barbet 全量 GPU 資料適配測量

使用者追加要求：參考文獻，使用 GPU 檢查資料品質及是否適合模型。現有全量來源處理持續，新增 frozen-v26 forward-only 測量；不更動權重、不以模型評分取代來源正確性。

完整工作範圍

全部 full-v4 匯出列都必須有 assistant-only conditional NLL、teacher-forced top-1、輸出層梯度 sketch norm 與七類 TRAIN 語義原型的 cosine。沒有抽樣列數上限。每列綁定原始檔 SHA-256、record ID、模型 revision 及計算程式。未跑完時不得宣稱全量 GPU 完成。

此外，對全部 2,000 個 authored TRAIN 根任務建立有／無 skill、有／無證據、answer-only 與反事實目標對照；共 15,430 個首個決策評分。1,715 組首個動作確實不同，另外 285 組首個動作相同，不把它們計為有辨識力的反事實。這是條件候選評分，沒有自由生成正確率宣稱。

已完成的數值控制

v26 revision 67131067ff1825179d5e38e91d499159669e9c66。原生 loader 保留 BF16 權重及必要 FP32 Mamba 參數。4 個真實序列的單筆／right-padded batch NLL 差為 0；gradient sketch cosine 最低 0.99999988。selected-position chunked NLL 與原生 dense loss 均為 2.08316969871521。輸出層解析梯度通過獨立小矩陣 autograd 檢查。

全部 2,000 個既有 TRAIN 根任務已計算語義原型，不使用 DEV、calibration 或 TEST。這些原型主要覆蓋比較、排序、binding、單位、規則版本、證據與操作狀態；不能代表所有數學、程式及一般知識能力。

解讀界線

  • 低 NLL 表示目前模型容易預測該答案，不能證明答案正確或有新增教學價值。
  • Readout-copy gradient 是將 tied embedding 的 readout 視為獨立副本的梯度，不是完整 tied-weight 或全模型梯度。
  • 使用文獻的 64 × 128 Rademacher 投影。其在 Barbet 上的選擇收益尚未由續訓證實；此處不是完整 LESS 重現。
  • IFD-like 與證據差值只作診斷。不套用論文閾值自動拒絕資料；移除證據後仍評原答案，不代表該答案在缺資訊狀態下應被接受。
  • GPU 分數不能推翻來源 HOLD，也不能讓 reference_only 自動成為已驗證 TRAIN。
  • 可學習性、未見組合遷移與同 checkpoint 能力保留需要真正的受控訓練與獨立驗收，目前保持 NOT_RUN。

主要文獻與採用範圍

  • https://arxiv.org/abs/2610.03702：Forward-only output-layer gradient sketch; applicability to Barbet is not assumed proven.
  • https://arxiv.org/abs/2402.04333：Targeted data relevance, do not conflate gradient similarity with correctness.
  • https://arxiv.org/abs/2308.12032：Model-specific instruction difficulty; later context ablation is separately reported, not the original complete IFD procedure.
  • https://arxiv.org/abs/2206.07137：Easy, hard and learnable are different; do not use loss alone as a truth test.
  • https://arxiv.org/abs/2411.06037：Separate evidence sufficiency from the model ability to use evidence.
  • https://huggingface.co/datasets/openbmb/UltraData-SFT-2605：Answer checks and actual training validation are distinct; this run does not reproduce the training validation.

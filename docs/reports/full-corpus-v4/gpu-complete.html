低 NLL 掩蓋的語義錯誤

對所有 2,000 個既有 TRAIN 根任務，建立原題、語義反事實、不變改寫、移除 skill、移除證據與 answer-only 等 15,430 個候選評分輸入。1,715 組首動作確實不同，285 組首動作相同而不適合此成對指標。原題與反事實都必須偏好各自正確答案才算成對通過。另同時報告總 log probability 與長度正規化結果，避免隱藏長度偏差。

增益定義為「移除後 NLL − 完整輸入 NLL」，正值代表加入內容提高參考答案機率。移除證據後仍評同一個 gold，只測機率敏感度；缺證據時的正確行動可能改為補查或澄清，因此不能把此數字當作缺證據作答準確率。這些是 TRAIN 上的診斷，不是封存 TEST 或泛化成績。

獨立覆核已重建所有 9,430 個原題／反事實／不變候選的實際 prefix 與 target，並核對全部 15,430 個評分身分。比較 287 組、排序 286 組、版本規則 284 組的兩個候選只差 operation 欄位。結果支持優先保留語義對照與操作綁定；不能把其中 NLL 較高、但條件下正確的一側刪除。

對資料課程的實際處理

  • 每筆 GPU 測量以 record_id 與原資料對齊，保留來源、品質範圍、split、root 與 parent 身分。
  • 同一完整輸入的既有 frozen-v26 勝出答案保持不變；不同條件的反事實不是同題答案競爭，不適用擇低 PPL 刪除。
  • 不按全資料 NLL 或 cosine 全域排序決定去留；這會偏向熟悉格式，也可能削弱數學、繁中、自然指令與價值對齊內容。
  • reference_only 不因低 loss 轉成已驗證資料。台灣主權、人民自決、普世人權與原始事實／引述忠實性，不因學生模型意見不同而移除。
  • 50% 一般能力、50% 語義課程仍只是按 supervised-token 曝光的候選配比。有限圖資料占比很大，不能直接均勻取樣全部一千萬筆。

數值驗證與文獻依據

實際 Barbet 控制中，短序列 dense NLL 與只投影監督位置的 NLL 都是 2.083169699；單筆與 batch 的 NLL 比對、sketch cosine 與小矩陣 analytic/autograd 對照均通過。權重與 native loader 固定，保留必要 FP32 參數，沒有改 tokenizer 或使用 MiniCPM tokenizer。

  • LESSER（2026 預印本）：採用 forward-only、雙側 Rademacher 的 readout gradient sketch。此處只測 detached readout copy，並非 tied embeddings 的完整梯度，也沒有聲稱其 Barbet 選料效果已獲訓練驗證。
  • LESS：借鑑目標能力相關性；沒有重現其 warmup 與 optimizer-aware influence。
  • Instruction-Following Difficulty：另報 answer-conditioned 與 answer-only 的 NLL 比值。此處是凍結 v26 的 IFD-like 診斷，不是原論文完整流程，沒有套用其門檻篩掉資料。
  • RHO-LOSS：區分已會、值得學與可學；支持不用 loss 單獨判斷資料真實性。
  • Sufficient Context：資訊充分和模型能利用資訊是不同問題。
  • UltraData 官方資料卡：資料品質與小型訓練後的用途驗證分開。本次沒有重現其訓練驗證。

八張 GPU 平行補完

單張 GPU 的網路續跑曾被明確記錄的 SIGTERM（退出碼 -15）中斷，以使用其餘七張閒置 GPU；這次受控切換並非原始下載失敗。切換時已完成 9,545,945 筆、1,496 個分片，其收據與輸出保持不變。只把剩餘 473,016 筆、147 個分片重新分配到八張本機 GPU；每個分片仍使用原始完全相同的批次與評分計算。32 筆實際 v26 數值控制的 NLL 差異為零，梯度方向與 token 命中對照通過。八個實際補跑程序全部成功退出後，才確認原邏輯 rank 0 的工作完成；原始失敗和受控中斷都保留。分配計畫、實際退出碼與完整證據。

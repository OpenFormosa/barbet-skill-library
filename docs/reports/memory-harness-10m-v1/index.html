Barbet：一千萬筆記憶、技能與工具資料

已完成資料工程與發布目標。HF 固定版本包含 10,328,696 筆合格新 episode、10,177,015 個不同標準化首問，以及 9,787,683 個任務家族；現役舊資料為 0。所有 5,521 個公開檔案、共 86,259,025,202 bytes，已經匿名完整下載並核對 SHA-256。這個完成狀態指資料、harness 介面及發布驗收，沒有訓練模型，也沒有新增能力提升或追上 9B 的測量。

標準答案遵守指定的 v26 規則。同一完整輸入有多個合格答案時，全部使用固定 native Barbet v26 計算條件答案 PPL，保留最低者。PPL 是 exp(監督位置負對數機率總和 / 監督 token 數)；只有 supervised assistant tokens 和 assistant EOS 進入分母，prompt、memory、tool observation、未監督歷史與 padding 不計入。原生 batch size 為 1，輸入不裁切；全部競爭分數必須有限，完全同分依穩定 record ID 決定。不同字面輸入或觀察條件不混為同一組。只有一個合格答案的題目標為未量測，不補造 PPL。新發現有問題的題目整題移除，不以次低答案代替。低 PPL 是模型似然，不是正確性的證明。

外部記憶如何進入資料。模型在作答前可見的 user context 中取得帶來源的記憶，或者先呼叫已註冊的工具，再取得真實 observation。前置和後置都是答案之前的上下文；不是把答案後的資訊回填成既有知識。來源與建立資料時的計算軌跡存於 metadata，推論 adapter 不會把它們自動加入 prompt。訓練 labels 對 prompt、記憶和 observation 使用 -100，只監督指定的 assistant 位置。

新增 4,547,341 筆 Wikidata 記憶題。只讀取原作者的 inductive 訓練圖譜與別名，沒有使用 Wikipedia 文章。原始 20,496,514 條訓練關係中，因名稱缺漏而排除 14,968 條，沒有自行補造實體名。檢查 4,554,029 個來源 anchor，排除 6,673 個超過完整鄰接預算的 anchor，以及 15 個首次未通過的 anchor，得到 4,547,341 題。每題獨立使用 SQLite 重算目標；2,974,827 次實際工具觀察都可從保存的 facts 重建。題型為一至兩跳投影、不同終點計數，以及集合聯集、交集、差集。

Wikidata 首次診斷是 21 ACCEPT、15 REVISE，36 題在審查前已通過獨立 SQL。部分評審聲稱缺少實際已存在的證據或 JSON 不完整，與保存的完整請求相矛盾；15 題仍持續隔離。這個比率不是全資料錯誤率。原始訓練／驗證／測試圖譜的實體沒有交集；新的 SFT 切分按 anchor 家族，其他上下文實體或 facts 仍可能共享，不能當成 entity-disjoint 評測。

新增 871,260 筆 ConceptNet 詞典記憶題。完整讀取 34,074,917 列原始資料，這一批僅採用 Wiktionary en/fr/de 與 WordNet 3.1 的英文概念紀錄。詞典範圍共 2,847,001 條 facts；1,303,855 個 subject URI 合併為 871,550 個基礎詞彙，432,305 個 URI 變體不另算題數。排除 283 個過大鄰接與 7 個首次未通過的基礎詞彙，得到 871,260 題。488,568 次工具觀察逐次重建核對。首次診斷為 18 ACCEPT、7 REVISE；7 題持續隔離。每條來源 assertion、關係方向、詞性／詞義 suffix、授權與 contributor metadata 均保留。

兩個新來源的完整索引都確認每題只有一個答案，因此全部明確標記未量測 PPL。它們使用少數集合查詢程序搭配不同的來源實體或詞彙；約 541 萬列不代表約 541 萬種不同推理算法。精確查詢驗證證明答案符合提供的有限資料，沒有證明每條來源敘述都是真實或最新世界事實。

這兩批占全資料 52.46% 的 episode，但只占 Pangolin 受監督 tokens 的 9.94%，以及 MiniCPM5 受監督 tokens 的 12.74%。原因是多數輸入是外部記憶，答案則是短 JSON。之後訓練應同時控制來源、題型、受監督 tokens 和完整上下文的計算成本；單純按列均勻抽樣不能保證 coding、語意工具選擇與修復能力得到足夠訓練。本次沒有藉由這些比例宣稱任何尚未量測的訓練收益。

Coding、tool use 與 refinement 的界線。資料包含 1,244,928 筆 coding episode，以及 2,878,189 筆 tool-use episode。OpenCode 的既有公開測試與評審分數依來源保留，但沒有在這次工作中執行下載程式。IFM coding 保留完整可靜態解析的 Python 回答，並隔離已發現的重複字典鍵、額外不可解析 fence 與缺少 observation 的特定執行聲稱。實際觀察、來源報告成功、靜態語法與語意正確性是不同驗證層級。標為 recorded_error_followup 的 episode 為 135,736 筆；沒有錯誤及修復歷史的圖譜列不算 refinement 樣本。

library 提供可明確註冊的 relation_lookup、snapshot 雜湊還原、有限查詢 verifier、以及至多三次候選的 refinement loop。verifier 回饋綁定候選 SHA-256，重複答案、步數耗盡和未完成生成均保留狀態。文件裡出現工具名稱不會自動成為可執行工具。介面說明區分從第一回合評測工具選擇，與給定既有 observation 後評測最後答案；不能把未來 observation 預先交給模型，再宣稱模型完成檢索。

以 MiniCPM5-2B 原生介面驗證。參考固定 revision f97400052a43d642bbc6e9975e2397e3ae6a6b52 的 tokenizer 與聊天模板；參數盤點為 2,516,756,480。完整輸入加 4,096 token 輸出預留不得超過 131,072 tokens。公開提供 records、Pangolin tokenized、minicpm5_tokenized 三種 config，完整陣列皆回讀核對。不同 tokenizer 的 IDs 不能互換。另逐題實測兩種答案隱藏 Qwen 請求的實際 token 預算；這是介面／長度驗證，不是 Barbet backend 認證或 MiniCPM 能力提升證據。

來源篩選沒有把原始列數直接當成果。已參考你提供的 awesome-agent-dataset 與 awesome-chatgpt-dataset，固定當時讀取的版本及 hash，並另行核對原作者來源。OpenMathInstruct-2 的 13,972,791 個答案列只有 606,883 個不同問題，未完成全部合格版本的 v26 比較，因此本次該來源沒有新增收錄。Dolci 的來源內容授權與部分工具 observation 契約仍有未解項目；SYNTH 的首輪檢索診斷未全部通過；Infinity 的 gated 存取與 UltraData 的禁止重新散布條件沒有繞過。這些未通過來源不計入目標。

從 v26 診斷對應到工程改進。先前固定 514 題的小型診斷中，原生 v26 的數學 0/127、fresh tools 4/127，而工具格式可解析有 105/127；這顯示格式與正確工具語意需要分開看，也有輸出長度與終止問題。現在資料採用明確 messages/tool schema、實際 observation、assistant-only masks、完整請求預算及可驗證的有限查詢。這些是資料與介面的改進，不能直接換算成新模型分數；原診斷也不是完整官方 benchmark。詳見早期設計與封存診斷。

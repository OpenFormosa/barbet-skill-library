查到的問題與處理

HF base 名稱目前指向已 SFT release。歷史 pre-SFT 亦已接受 attention/surface-binding 專項適配，不能冒充原始預訓練底模。初次閱讀重整也因 query_hash 無法區分同問句不同文章而停止；v2 改用 pinned upstream task ID，保留第一次失敗與輸出。首輪 backend tool-history fixture 缺 system message 已另版修正，未作成訓練樣本。

資料與能力的界線

題目／oracle／工具的正確性不等於模型學會。Source index 不自動授權所有舊 rows 重新 SFT。閱讀課程不是完整一般能力保留配比；語義試作共用 atomic program graphs，尚非未見組合遷移驗證。A/B 配比、訓練 parent、Megatron parity、保留與 1M 自由生成仍待獨立 gate。

舊 HF main 與既有 checkpoint 未改。候選分支 semantic-curriculum-v3-20261104 保留 staging 標記，完成所有新檔案匿名 byte readback 後才發布最終 manifest。私有 oracle、calibration、sealed test 不公開。

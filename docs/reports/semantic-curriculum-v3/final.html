二、針對原先失敗補強

  • 條件與操作：gt/ge、lt/le 的資料包含等於門檻的值。每組反事實必須改變 oracle 答案，無關改寫必須保持答案。
  • 排序與規則：平手會影響選中順位；虛構 v1/v2 規則定義與有效版本均可變，避免把版本名當答案。
  • 參數綁定：另有 315 筆公開撤提示 views，只給顯示名稱、欄位意思。正確工具 row ID／field code 不在問題裡；host 只能解引用模型選中的值。
  • 未知與狀態：資料涵蓋來源充分、可補查、規則缺漏、來源衝突、不可取得，以及提交／執行／部分／失敗／取消／完成。
  • 正常回答：自然閱讀不用統一機械格式；所有接受的 assistant targets 包含必要 EOS，工具觀察不計 SFT loss。

核心 140 個問法 frame 接受 133、隔離 7。撤提示另有 12 個候選，接受 6、隔離 6。Codex 額外逐句覆核抓到 teacher 把「保留 JSON 型別」誤放行成「另報型別」；相關首輪 holds 未解除。新的審核 protocol 先通過正負控制，再審全新候選。這仍不是人工標註，更不能替代學生學習實驗。

四、來源分布與保留問題仍存在

完整索引中，5,414,792 筆有明確有限圖查詢語義，4,604,175 筆僅憑 metadata 仍不能確定能力家族。來源池的規模不是有效課程規模。自然閱讀尚不能代表一般指令、數學、程式與知識保留 mix；本輪沒有以全量原資料再訓練。

七個 atomic 家族有多個數值、實體、措辭與前後位置變體，但新操作組合、外部自然來源 transfer 尚未成立。資料最大 total budget 為 8,192；沒有新 128K／256K／512K／1M SFT 樣本或自由生成驗收。遠端 516 題逐題紀錄未取得，因此未宣稱完成其全部近鄰除汙。

五、Barbet 與工程紀錄

實際核對 OpenFormosa/barbet-1b-base@004ef70881dcb87f1b423951bd418f1748db8b13 的權重、config、tokenizer 與 release code。該名稱目前指向 已 SFT 的 release，29 blocks、22 attention／7 Mamba、原生 1,048,576 context；BF16 1,118,798,760 elements、FP32 336 elements。前身 4dbb352... 亦已接受 attention／surface-binding 適配，真正未適配的祖先尚未確認。

新增真實原生 Barbet adapter，保留精度與 hash 邊界。Smoke 僅測 14／290-token prompts，各產生 12 tokens 並碰到輸出上限。三個 cache 步驟 top-1 相同，最大 logit 差異為 0／0.15625／0.21875。這不是 Megatron parity、1M serving 或能力通過證明。Training parent 保持未選；未改模型權重。

現有七個 skill 契約已補強，總數維持 65。新 harness 將 raw proposal、host validation、真實執行與 final proposal 分開；沒有私有 oracle feedback，沒有把 arbitrary code 的 AST 檢查冒充 sandbox。

六、成本、問題修復與下一步

本地 Qwen teacher 已驗證 32 次 API 呼叫：48,384 prompt／26,653 completion tokens。8-GPU server 約 0.903 小時，配置時間約 7.223 GPU-hours，包含載入與閒置。訓練 GPU-hours＝0。Teacher 已關閉，所持有程序全部退出，GPU 記憶體歸零。

本機 Qwen/Qwen3.8-Flash-Next-FP8，revision 236dfdf285828023ca3bcd3f37366c58a3469b13；最多兩個工作槽。12 個正反控制全通過，測試包含台灣自決、反族群貶抑、批評台灣政府、忠實翻譯不同立場，以及拒絕迫害、竄改引文與未授權侵害。審核先固定樣本、完整輸入與嚴格 JSON schema，不截斷、不重試負面結果求通過，完整量測 served tokenizer 與預留輸出。

357 筆固定樣本得到 ACCEPT 345, REJECT 7, REVISE 5。來源分層採各來源最低 hash 8 筆，另含原對話篩查未命中的固定 256 筆，以及全部 13 個規範／官方引述案例。工具定義補掃後，實際仍未命中的樣本為 256 筆，其結果 {"ACCEPT": 249, "REJECT": 3, "REVISE": 4}。這是診斷樣本，不是全語料錯誤率或價值合格率估計。負面模型判定也可能有誤；保留第一判定並隔離，不把它直接宣稱為已證實違規。

價值與 PPL 的先後

先符合品質與價值納入條件，再使用已凍結的原生 v26 最低 PPL 排名。PPL 只衡量模型熟悉程度，不證明正確、誠實或價值合格。保留的多答案 winner 維持原排名，不因這次審核改換答案。訓練仍使用 Barbet tokenizer、assistant-only labels、barbet_portable_v1；不需要 MiniCPM tokenizer。

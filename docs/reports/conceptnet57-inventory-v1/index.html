ConceptNet 5.7：有來源的詞彙檢索

原始公開檔共 34,074,917 列，完整壓縮檔及解壓資料雜湊已核對。保留原始 assertion URI、詞性／詞義 suffix、關係方向及正負語意，並保存逐條來源與授權；不把來源敘述認定為已核實的世界事實。

本批只使用英文概念兩端、來自 Wiktionary en/fr/de 或 WordNet 3.1 的詞典紀錄，排除其他群眾來源。詞典範圍共 2,847,001 條紀錄；1,303,855 個 subject URI 合併成 871,550 個基礎詞彙 anchor，432,305 個詞性／詞義 URI 變體不另外增加題數。每個基礎詞彙最多一個固定題目與記憶位置。

首次 25 題語意診斷為 18 ACCEPT、7 REVISE；7 題全部保留隔離。25 題的完整實際請求均已核對；精確 SQL 與證據集合一致。部分評審指控缺少 JSON 引號或證據，與保存的字串矛盾；有些評審明確說答案正確卻選 REVISE。這些診斷票數不能當作資料錯誤率，也不會重跑到通過。

另有 1,024 個固定抽樣的基礎詞彙通過完整編譯、三種 config 回讀及候選封存還原，618 個實際工具 observation 可重建。全池儲存外推約 6.59 GB，只是估計而非上限。完整候選建置已啟動，尚無本來源資料計入 HF。

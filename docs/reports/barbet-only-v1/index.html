過去稱為 Pangolin 的 tokenized 輸出就是此處的 Barbet 原生訓練 IDs。Tokenizer JSON SHA-256 為 f84754e42cc4b08d5573a6b7306635e86ed04fff68ee707662d76d7044917176，與固定 Barbet v26 tokenizer 一致。若使用其他 Barbet checkpoint，訓練前應核對 tokenizer 是否相同。

from datasets import load_dataset
train = load_dataset("OpenFormosa/barbet-long-context-sft", "tokenized",
                     revision="d82521e2c6aa16377b014c4e6d1af6b746bd5c04",
                     split="train", streaming=True)

保留現有 labels。Prompt、memory、工具 observation 的位置是 -100；只監督指定 assistant tokens。Collator 應保留這些 masks，padding labels 也使用 -100；causal trainer/model 對 labels shift 一次。既有 IDs 不需要再 tokenize，也不應再套一次聊天模板。records 中歷史輔助 mini/minicpm 欄位仍保留於來源紀錄，Barbet 訓練只需 tokenized 的 input_ids 與 labels，不需要 MiniCPM tokenizer。

v26 選答規則維持有效。同一完整字面輸入、記憶與工具觀察有多個合格答案時，按固定 native v26 的最低條件 supervised-answer PPL 選取。共 576,095 筆經競爭答案比較，9,752,601 筆單一合格答案明確標為未計分。首次隔離與來源品質規則全部保留，沒有再次生成或改選答案。

驗證範圍。本次完整重讀並核對 1,502 個 Barbet tokenized 分片的檔案雜湊、筆數、token 總數與長度預算。所有保留檔案的遠端 Git 物件均與先前已完整匿名下載核對 SHA-256 的父版本一致；新的資料卡、載入說明、訓練資料設定與發布證明另行匿名下載核對。這是父版本完整回讀加上未變動物件與新 metadata 的組合驗證，沒有宣稱本次重新下載所有歷史檔案。

目前完整長度分桶只採用 Barbet token 數，數值見 統計 JSON。先前以兩種 tokenizer 較長者分桶的歷史值仍保留於原一千萬筆來源報告。來源授權、獨立 SQL、工具觀察、切分與資料品質限制沿用原報告；本次格式修訂沒有訓練權重或新增模型效能測量。

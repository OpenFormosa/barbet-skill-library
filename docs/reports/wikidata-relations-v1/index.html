Wikidata5M：外部記憶、關係檢索與可驗證答案

從原作者的 inductive graph 和實體／關係別名檔建立來源庫，只使用原始訓練關係。原始訓練、驗證、測試實體完全不重疊。此研究範圍是 CC0 結構化資料，未下載或重新授權 Wikipedia 文章內容。

原檔缺少 4,840 個訓練實體名稱及 3 個關係名稱；原完整覆蓋檢查因此失敗，紀錄保留。後繼版本沒有補造名稱，排除相關 14,968 條關係，逐列重比原始資料，剩 20,481,546 條可用關係。上述數字是來源 facts；實際收錄的訓練題數另列於後。

題型依提供紀錄進行方向正確的一至兩跳查詢、不同終點計數、聯集、交集與差集。每個實體最多一題，不把前後記憶位置或不同答案樣式算成新題。查不到只表示該有限資料庫沒有紀錄，不能當成真實世界否定。有限集合程式與獨立 SQLite 分別計算標準答案；執行的是我們的資料查詢器，從未執行下載來源程式。

首次 36 題全部通過獨立 SQL 答案比對；Qwen 評審為 21 ACCEPT、15 REVISE，15 題保留隔離。核對完整實際請求與答案後，多個評審指控與實際 JSON 矛盾，例如已有證據 ID 卻稱缺漏，或聲稱正確但選 REVISE。此抽查比例不是資料錯誤率，也不是模型提升證據。

新增可攜的工具狀態只放入 metadata，不改首批任何模型輸入、答案、tokens 或 labels。36 題逐一驗證相同，32 次實際查詢觀察都可由下載資料重建。應用程式需明確註冊只讀 relation_lookup；文件文字不能自動註冊工具。候選驗證綁定答案 SHA256，錯誤會回傳可定位的範圍，超預算不截斷。

1,024 個固定抽樣來源實體的儲存探測得到 1,021 筆可編譯資料，完整文字、兩種 tokenizer 陣列及壓縮候選合計約每筆 11 KB；對全池的 50.09 GB 外推只是估計，仍須預留去重、切分與發布證據空間。完整來源處理已完成：4,547,341 個候選全部通過獨立 SQL；完整索引確認每題只有一個答案，工具軌跡與新舊切分檢查均通過。全部 4,547,341 筆完整訓練檔及推論請求檢查已通過，已發布至 HF 並完整匿名回讀核對。

來源：原作者專案；Wikidata 結構化資料政策。

單一版本明確標示未量測 PPL；若同完整輸入出現其他合格答案，仍必須以固定 v26 逐一計分比較。每個來源 anchor 一題，前後位置不重複。新的 SFT 切分按 anchor 家族，其他上下文實體可能共享，不能宣稱為 entity-disjoint 評測。

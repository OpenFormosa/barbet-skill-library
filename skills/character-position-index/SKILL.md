## Use When

需要快速查詢字串中特定字元首次出現位置時；處理字串解析、索引構建或去重定位任務時。

## Do Not Use When

需要記錄字元所有出現位置時；需要最後一次出現位置時；處理非字串類型資料時。

## Inputs

輸入為一個 Python str，以 Unicode 字元計數而非 UTF-8 bytes，索引從 0 開始。

## Procedure

1. 初始化一個空的字典用於儲存結果。2. 檢查輸入是否為空字串，若是則直接回傳空字典。3. 遍歷輸入字串的每個字元及其索引。4. 檢查當前字元是否已存在於字典中。5. 若不存在，將該字元作為鍵，當前索引作為值存入字典。6. 若已存在，跳過該字元以保留首次出現的位置。7. 遍歷結束後，回傳構建完成的字典。

## Output Contract

回傳一個字典，鍵為字串中的唯一字元，值為該字元在原始字串中首次出現的整數索引。

## Failure

僅對字串有效域承諾程序；非字串類型及環境資源異常未定義，依呼叫者契約處理，不要求拋出特定錯誤或自動轉型。

## Validation

確認回傳結果為字典類型；驗證空字串輸入回傳空字典；隨機抽取字串檢查每個字元的索引是否對應其首次出現位置；確認重複字元未被覆寫。

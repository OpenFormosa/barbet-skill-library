## Use When

需要從已提供或可檢索的文件選出下一步可使用的證據，且上下文空間有限時。

## Do Not Use When

沒有可讀來源，或任務只要求創作、不需要來源支持時。

## Inputs

目前子問題、具來源 ID 的原文片段、實體／時間／版本限制及輸出預算。

## Procedure

1. 指出本步要確認的實體、屬性與條件。2. 找到直接相關的原文，連同否定、單位、指代及例外一起保留。3. 輸出可回查的來源 ID 和逐字引句，不把自己的改寫當原文。4. 將引句所述與待回答問題逐一比較；來源出現某個值，不代表該值屬於目標實體。5. 預算不足時保留來源定位，另開一步讀取需要的範圍，不靜默刪掉條件。虛構教學例：來源「甲館週一不開放；乙館週一開放」，查甲館時必須保留「不」。

## Output Contract

提供來源 ID、原文引句及尚未確認的條件。只有執行器核對原文後才能標記來源吻合；此標記不代表結論正確。

## Failure

找不到符合實體、屬性及條件的片段時回報具體缺口；不要把相近主題或搜尋排序分數當成正確證據。

## Validation

核對來源版本與引句位置；再獨立檢查實體、屬性、時間、否定及例外。相似但不適用例：使用者要求寫虛構故事時，不以此程序阻止創作。
